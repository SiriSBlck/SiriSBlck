# 💫 About Me:
Hello, world! I'm a Mathematics and Software Engineering student in Universidad Politécnica de Madrid, with knowledge in Full Stack development and special interest in backend and middle-end. 

I am currently working on Project Manager, a managing system of an e-commerce shop with a Spring Boot backend, React frontend with Jsx and Sass, MySql Workbench as DBMS, a Node.js and JWT tokens stored in cookies middle-end controlled by a filterchain and protected with Spring Security.
